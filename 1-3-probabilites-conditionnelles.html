Aide-mémoire

À retenir

Une conditionnelle est un rapport entre deux zones : la partie commune sur le nouvel univers.

Probabilité totale : on additionne tous les chemins qui mènent à B, c'est-à-dire toutes les zones Aᵢ ∩ B.

Bayes est une probabilité conditionnelle : la zone Aᵢ ∩ B sur toute la zone B.

NotionFormule
Probabilité conditionnelleP(A|B) = P(A ∩ B) / P(B), si P(B) > 0
IndépendanceP(A ∩ B) = P(A) · P(B)
Règle de multiplicationP(A ∩ B) = P(B) · P(A|B) = P(A) · P(B|A)
Probabilité totaleP(B) = P(A₁)P(B|A₁) + … + P(Aₙ)P(B|Aₙ)
Formule de BayesP(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / [P(A₁)P(B|A₁) + … + P(Aₙ)P(B|Aₙ)]

Pièges

  • P(A|B) ≠ P(B|A) : même numérateur, dénominateurs différents.
  • Incompatibles (A ∩ B = ∅) ne veut pas dire indépendants : c'est même le contraire.
  • Une partition couvre tout l'univers, sans chevauchement.
  • Une probabilité conditionnelle élevée décrit une association, jamais à elle seule une cause.
