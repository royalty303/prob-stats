# Probabilités et statistique — en images

Site de révision du cours 201-SN1 (Collège Laflèche) : *comprendre le cours par l'image*.

- `index.html` : accueil et plan des six chapitres
- une page HTML par section (ex. `6-2-khi-deux.html`)
- `assets/style.css` : style commun · `assets/commun.js` : outils de dessin communs
- `assets/<section>.js` : figures et simulations de chaque section

Code de couleurs : encre = observé · bleu pointillé = modèle, H₀ · orange = écart qui compte, rejet.

Site statique, aucune compilation : activer GitHub Pages sur la branche `main` (dossier racine).
