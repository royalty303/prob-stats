4.1 · Introduction aux variables aléatoires continues

Une variable continue peut prendre toutes les valeurs d'un intervalle. Les probabilités ne sont plus des barres : ce sont des aires sous une courbe.

Aide-mémoire

À retenir

Une densité f(x) n'est jamais négative et l'aire totale sous la courbe vaut 1.

P(a ≤ X ≤ b) est l'aire sous la courbe entre a et b.

P(X = a) = 0 : il faut toujours un intervalle. Ainsi, P(X ≤ a) = P(X < a).

NotionFormule
ProbabilitéP(a ≤ X ≤ b) = ∫ab f(x) dx
Aire totale∫ f(x) dx = 1 (sur toutes les valeurs possibles)
Espéranceμ = E(X) = ∫ x · f(x) dx
Varianceσ² = Var(X) = ∫ (x − μ)² · f(x) dx
Écart typeσ = √Var(X)

Pièges

  • La hauteur f(x) n'est pas une probabilité : seule une aire en est une.
  • Pour un trapèze couché sous une densité, les « bases » sont les deux hauteurs f(a) et f(b), et la « hauteur » est la largeur b − a.
